# COD Payout

A small Databricks Asset Bundle I built to learn DABs. It runs a daily job that works out how much each brand should be paid for delivered COD orders.

The data is fake, generated by a setup job.

## What the job does

1. Picks delivered COD bags that haven't been paid yet
2. Calculates the payout per brand (bags with bad numbers are put on hold)
3. Writes a payout Excel file and marks the paid bags in a ledger
4. Updates a `bag_journey` table for the dashboard

It runs every day at 7 AM IST in prod. In dev, the schedule is paused.

## Folder structure

```
databricks.yml        bundle config, dev and prod targets
resources/            job and storage definitions
src/setup/            creates the sample data
src/cod_payout/       the four job steps
```

## How to run

```bash
databricks bundle deploy
databricks bundle run setup_sample_data
databricks bundle run cod_brand_payout
```

You can also deploy from the Databricks UI: open `databricks.yml` in a Git folder and click Deploy.
